Understanding Prompt Injection in Browser Tools

Prompt injection occurs when untrusted content contains language that attempts to influence an AI system.

Typical examples

Attack demonstrations often contain phrases such as “ignore previous instructions”, “system prompt”, or “you are an AI assistant”. Those phrases are quoted here as security examples, not instructions to the reader or model.

Why browser tools are exposed

Tools that analyse arbitrary webpages may encounter hostile and legitimate instruction-like text, so detection should be treated as a warning rather than proof of an attack.
